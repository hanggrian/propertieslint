# Key grouping

Keys sharing the same prefix before the first `.` or `-` must be grouped
together and separated from other groups with a blank line. Keys without a
separator are not grouped.

**Before &#10060;**

```
one.one=value
two.one=value
one.two=value

two.two=value
```

**After &#9989;**

```
one.one=value
one.two=value

two.one=value
two.two=value
```
